# Object_Oriented_Programming_Fundamentals
# Fundamentos de Programación Orientada a Objetos en Java

## Descripción

Ejercicio práctico desarrollado en Java que representa la administración de estudiantes y cursos mediante programación orientada a objetos.

El programa permite crear estudiantes, consultar sus calificaciones, verificar si aprobaron, actualizar su año académico y registrar estudiantes en cursos.

También incluye operaciones para consultar el número de estudiantes inscritos, obtener la mejor calificación, calcular el promedio y mostrar un ranking del curso.

## Objetivo

Practicar los fundamentos de la Programación Orientada a Objetos (POO) en Java mediante la creación de clases, objetos, constructores y métodos, así como la interacción entre diferentes clases.

## Contexto

Ejercicio práctico de aprendizaje enfocado en reforzar los fundamentos de Java y la aplicación de conceptos de programación orientada a objetos.

## Pasos realizados

1. Crear la clase `Student` para representar a los estudiantes mediante atributos como nombre, matrícula, calificación y año académico.
2. Implementar constructores para inicializar los objetos `Student`.
3. Desarrollar métodos para mostrar el nombre completo y verificar si un estudiante aprobó.
4. Implementar la actualización del año académico cuando el estudiante cumple con la calificación mínima aprobatoria.
5. Crear la clase `Courses` para representar los cursos y administrar la lista de estudiantes inscritos.
6. Implementar métodos para inscribir y cancelar estudiantes.
7. Incorporar operaciones para contar estudiantes, obtener la mejor calificación y calcular el promedio.
8. Desarrollar métodos para mostrar el ranking y comparar las calificaciones con el promedio del curso.
9. Utilizar la clase `Main` para crear objetos y probar las funcionalidades implementadas.

## Resultado

Se desarrolló un ejercicio en Java que permite modelar la relación entre estudiantes y cursos, aplicar operaciones sobre sus datos y realizar consultas relacionadas con el desempeño académico.

## Aprendizajes

- Creación de clases y objetos en Java.
- Declaración y uso de atributos.
- Implementación de constructores.
- Uso de métodos con y sin valores de retorno.
- Encapsulamiento como concepto de POO.
- Relación e interacción entre clases.
- Manejo de listas mediante `ArrayList`.
- Uso de ciclos `for-each` y estructuras condicionales.
- Cálculo de promedios y comparación de valores.

## Tecnologías utilizadas

- Java
- Java Collections Framework (`ArrayList`)
- Programación Orientada a Objetos (POO)
